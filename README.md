# Карточка товара DNS — Vue

Локальный Vue 3 + Vite прототип по третьему скриншоту. Под блоком «Добавьте товар в сборку» размещена карусель готовых ПК: фотографии корпусов, цены, процессор, видеокарта, память и SSD в названии.

## Запуск

```sh
npm install
npm run dev
```

Сборка: `npm run build`. Просмотр сборки: `npm run preview`.

Для установки `@dns-modules` нужен доступ к корпоративному реестру DNS. Адреса реестров указаны в `.npmrc`, секреты и токены не используются.

## Использование дизайн-системы

Компоненты и их API выбраны по локальному Storybook в `D:/Git/DNS/dnsdesignsystem-main`:

- `BaseUiButton`, `BaseUiIconButton` — основные действия, конфигуратор, навигация карусели.
- `BaseLink` — ссылки и названия товаров.
- `Breadcrumbs` — навигационная цепочка.
- `Checkbox` — сравнение товара.
- `ActionTag` из `@dns-modules/tag` — серый кликабельный тег «Собрать ПК» в заголовке виджета.
- `BaseUiInputSearch` — поиск в шапке.

- `@dns-modules/font-pt-sans` — шрифт PT Sans; локальные файлы шрифта подключены через стандартный CSS `url()` для Vite.

`src/styles/dns-tokens.css` скопирован из `src/assets/design-tokens/tokens.css` указанной ДС. Карточка товара, конфигуратор и виджет собраны композицией этих элементов; готового Vue-компонента товарного виджета в предоставленном репозитории нет.

## Поведение прототипа

Работают переключение и увеличение фото, избранное, сравнение, добавление в демонстрационную корзину и сборку, прокрутка и раскрытие списка сборок, просмотр их состава, переходы на DNS. Поиск открывает поиск на DNS. Состояние интерфейса хранится в памяти вкладки.

Цены и доступность блока питания сохранены со скриншота. Цены сборок демонстрационные; первые три конфигурации основаны на сборках со страницы DNS, остальные показывают варианты наполнения виджета. Бэкенд, реальная корзина и оформление заказа не подключены. Видео открывается на DNS, без локального воспроизведения.

Виджет обновлён по `Widgets / productSlider`, узлы `4854:13250` и `4876:35240` файла `x2nqb0yvBoSdd6BUFvM0rd`. Desktop: карточка 196 px, фото 160 × 160 px, промежуток 28 px; карточка при наведении 220 px, внутренние отступы 12 px. На мобильных: карточка 126 px и фото 100 × 100 px. Названия ограничены двумя строками. Стрелки на уровне ряда видны при наведении и навигации клавиатурой; недоступное направление скрыто. Карточка раскрывает сравнение, демонстрационный рейтинг, покупку и избранное поверх виджета без сдвига ряда. Подписи с числом комплектующих отсутствуют.

Файлы: `src/App.vue` — страница, `src/components/ReadyBuilds.vue` — виджет, `src/data.js` — данные сборок, `src/styles/ready-builds.css` — оформление виджета. Скрипт `scripts/download-assets.mjs` повторно загружает изображения из зафиксированных источников.


Хлебные крошки используют официальный шрифт @dns-modules/font-icon v3 (npm alias font-icon-v3). Адаптив карточки переключается на мобильную компоновку ниже 992 px, по CSS продовой страницы DNS. Блок характеристик содержит данные PL750D; ссылка PF750 служит образцом оформления.


Карусели аксессуаров, услуг и совместных покупок: названия, фотографии, цены и оценки сохранены со страницы DEEPCOOL PF750 DNS 19.10.2026. Исходные URL находятся в src/recommendations.json; вкладки используют @dns-modules/base-ui-tabs. Корзина, сравнение и избранное работают в памяти прототипа.


Блок отзывов и надёжности повторяет структуру PF750 на DNS: статистика 4.75 / 19611 отзывов, медиа покупателей, фильтры и надёжность 99.7%. В прототип загружены шесть коротких выдержек из реальных отзывов: сначала видны четыре, кнопка «Показать еще» раскрывает остальные. Лайк и дизлайк взаимно исключаются, повторное нажатие снимает голос; счётчик меняется локально. Комментарии раскрываются ссылкой с поворотом шеврона. Имена оформлены ссылками на DNS, аватар взят с продовой страницы. Меню с троеточием содержит копирование ссылки и переход к жалобе на DNS. Публикация комментариев, профили и модерация требуют DNS; бэкенд не подключён. Детализация обращений в сервис отображается постоянно; указатель плашки и отступы повторяют Figma 29050:50222.


Фильтры отзывов повторяют прод: табы «Все отзывы / Только к этой модели», SelectInline с четырьмя вариантами сортировки, теги с чекбоксами для фото, видео и оценок. Оценки можно выбирать одновременно. Верхняя лента отзывов отображает только целые миниатюры, помещающиеся по ширине (ResizeObserver), без скролла. VideoIndicator.vue использует один оригинальный SVG для верхней галереи и отзывов.
